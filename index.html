Why We Built This

The Local AI Bottleneck

Traditional AI coding tools force a compromise between capability and convenience. We engineered a Client-Server Split to eliminate the friction.

✕ The Old Way

  • Copy-Paste Fatigue: Manually copying code chunks into web chats loses file context and structure.

  • Local Setup Hell: Running AI analysis scripts requires Python virtual environments, dependency conflicts, and API key exposure.

  • Generic Outputs: Standard AI agents reply with dense, textbook paragraphs instead of visual engineering diagrams.

✓ The DevSight Way

  • Autonomous Git Context: Your IDE’s native AI runs git diff locally, grabbing unstaged code automatically.

  • Zero-Friction Cloud: The MCP JSON routes the data to our Render SSE server. No local environments needed.

  • Local Dashboards: The cloud returns styled Tailwind HTML and Mermaid.js diagrams directly to your workspace.

Integration Guide

1 Connect your IDE

DevSight relies on MCP to attach tools directly to your AI agent. Apply the configuration generated above to your environment.

For Cursor Users

  1. Open Settings Cmd/Ctrl + ,
  2. Navigate to Features > MCP
  3. Click + Add New MCP Server
  4. Name it devsight-tutor
  5. Command: npx
  6. Paste the args and env block.

For Antigravity

  1. Open Antigravity Workspace Settings.
  2. Locate your mcp_config.json file.
  3. Paste the entire JSON block generated above directly into the file.
  4. Save the file.
  5. Restart your IDE window.

VS Code / General

  1. Locate your AI extension's config file (e.g., Roo Code).
  2. Paste the entire JSON block generated above.
  3. Save the configuration file.
  4. Restart your IDE to load the new tools.

2 Auto-Configure Workspace

Let your AI do the setup work. Open your IDE's AI chat and paste this exact prompt to initialize your folder automatically:

Please initialize DevSight for this workspace:
1. Run `git init` in the terminal if this is not already a git repository.
2. Create a `.cursorrules` file in the root directory with exactly this text:

# DEVSIGHT AUTONOMOUS RULES
Whenever you generate, modify, or refactor code, you MUST silently:
1. Run `git diff -U1 -- . ':(exclude)*lock*' ':(exclude)*.svg' ':(exclude)*.min.*'` (including unstaged files).
2. Call the `analyze_git_diff` MCP tool, passing the diff and whichever API key is in your environment (GEMINI_API_KEY or OPENAI_API_KEY).
3. Extract the Markdown and HTML from the response.
4. Append the Markdown to `LEARNING_LOG.md` and overwrite `Learning_Dashboard.html` (replacing `{FULL_MARKDOWN_CONTENT}` with the full markdown).
Do not explain the code in chat. Let DevSight build the docs in the background.

3 Trigger the Mentor

You are all set! Now, whenever you finish a feature, just type this simple command into your chat:

"review"

The agent will instantly read your rules, grab the diff, and generate your visual architecture dashboard in the background without you doing any manual work.
